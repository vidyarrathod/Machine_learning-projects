# 🧠 Machine Learning Internship Projects

This repository contains two Machine Learning projects completed as part of my internship. Each project demonstrates core ML concepts, including data preprocessing, model building, evaluation, and visualization.

---

## 📌 Projects Overview

### 1️⃣ House Price Prediction 🏠

**Objective**: Predict house prices based on features like square footage, number of bedrooms, bathrooms, and location.

**Tools & Technologies**:
- Python, Pandas, NumPy
- Scikit-learn (Linear Regression, Decision Tree, Random Forest)
- Matplotlib, Seaborn for visualization
- Jupyter Notebook

**Highlights**:
- Data cleaning and feature engineering
- Exploratory Data Analysis (EDA)
- Built multiple regression models and compared performance
- Achieved high R² score with Random Forest model

---

### 2️⃣ Mall Customer Segmentation 🛍️

**Objective**: Group mall customers into clusters based on spending habits and demographic data.

**Tools & Technologies**:
- Python, Pandas, NumPy
- Scikit-learn (K-Means Clustering)
- Elbow Method & Silhouette Score for optimal k
- Seaborn, Matplotlib for cluster visualization

**Highlights**:
- Unsupervised learning using K-Means algorithm
- Segmented customers into distinct behavioral groups
- Used visual plots to interpret clustering output
- Helped derive business insights from customer patterns
